# My Portfolio ✨

In this portfolio I bring together my work in molecular biology research 🧬 and my software projects from 42 💻.

🚀 **Live site:** [mkcodes2.github.io](https://mkcodes2.github.io) ↗

## 📋 What's inside

- **Home**: who I am and my two worlds, side by side
- **Coding**: my 42 journey and selected projects (PongJam, miniRT)
- **Molecular Biology**: my BSc, thesis research and scientific presentations

## 🛠️ Built with

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router

The site is deployed to GitHub Pages with GitHub Actions on every push to `main`.

Most of the text lives in `src/content.ts`, so content updates rarely touch the components.

## 🖥️ Run it locally

You need [Node.js](https://nodejs.org/) (version 22 is used for deployment).

```bash
npm install
npm run dev
```

Then open the local address that Vite prints in the terminal.

To make a production build and preview it:

```bash
npm run build
npm run preview
```
